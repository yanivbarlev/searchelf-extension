# Chrome Web Store Listing — Tips for Google Sheets

## Name
Tips for Google Sheets - Tricks & Hidden Features

## Summary (132 chars max)
50+ Google Sheets tricks, hidden features & productivity tips — right inside your spreadsheet. Free & instant.

## Description

WHAT YOU GET
Discover 50+ curated tips, tricks, and hidden features for Google Sheets — delivered in a beautiful floating widget right inside your spreadsheet. Every time you open the widget, you get 5 fresh tips picked at random.

KEYBOARD SHORTCUTS
- Insert today's date with Ctrl+;
- Insert current time with Ctrl+Shift+;
- Toggle absolute references with F4
- Open menu search with Alt+/
- Open keyboard shortcut list with Ctrl+/
- Navigate to data edges with Ctrl+Arrow
- Find and replace with Ctrl+H

HIDDEN FEATURES
- QUERY function for SQL-like data queries
- SPARKLINE for in-cell mini charts
- ARRAYFORMULA to apply formulas to entire columns
- XLOOKUP as a modern VLOOKUP replacement
- FILTER, SORT, and UNIQUE for dynamic data manipulation
- Named ranges for cleaner formulas
- Data validation dropdowns and checkboxes
- Pivot tables and slicers for data analysis

WHY THIS EXTENSION
- 50+ handpicked tips from beginner to advanced
- Shows 5 random tips each time — always something new
- Works right inside Google Sheets — no tab switching
- Completely free, no account required
- No data collected, no tracking

## Permission Justifications

### storage
Stores user preferences such as dismissed tip state and last viewed tip index. No personal data is collected or transmitted.

### Host permission (*://docs.google.com/spreadsheets/*)
The extension needs access to Google Sheets pages to inject a floating tips widget that displays keyboard shortcuts and hidden features directly within the Google Sheets interface.

## Single Purpose Description
This extension displays helpful tips, keyboard shortcuts, and hidden features for Google Sheets users while they browse docs.google.com/spreadsheets.

## Privacy Disclosures
- Does the extension collect personal data? **No**
- Does it use remote code? **No**
- Does it transmit data to external servers? **No**
- Does it use cookies or local storage? **Yes** — only to store widget dismiss state (a timestamp). No personal data.
